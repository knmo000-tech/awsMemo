## 記録ルール

- 前提、継続方針、暫定推奨、正式決定、未決定を分ける。
- 利用者が指定した前提と、設計者からの提案を混同しない。
- 判断変更時は新ADRを追加し、旧ADRの冒頭から後続記録へ案内する。過去の理由は削除しない。
- 現行の結論はcurrentへ反映する。設定・担当・期限は決定事項一覧で管理する。
- 未確認の構築・試験・費用を完了済みとして記録しない。
