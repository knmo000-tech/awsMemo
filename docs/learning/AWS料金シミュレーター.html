⑥ 設計と見積もりの注意点

今回のシミュレーションに含めていない料金
  • CloudFront・API Gateway・Web Functionsの外部データ転送量、ログ、カスタムドメイン関連
  • Bedrock、SQS、Worker Lambda、DynamoDB、S3、Secrets Manager、CloudWatchなどの共通バックエンド
  • 無料枠、段階料金、CloudFront定額プラン、税金・為替、失敗時の再試行
  • WAFの追加本文検査、WCU超過、Bot Control、課金対象のマネージドルール
REST APIを採用する場合

Regional REST APIのステージにAWS WAFを直接関連付け。通常Lambdaで認証・ジョブ登録・状態照会。WAF設定、API管理、運用が単純で、短時間のREST APIに向きます。

Web Functionsを採用する場合

CloudFront＋WAFからOAC署名でIamAuthのWeb Functionsへ転送。オリジン直接アクセスをIAMポリシーで制限。JWT/Authorizationの転送・Webキャッシュ無効・企業間のリクエスト状態分離を検証します。HTTP並列処理やI/O待ちの多いAPIに向きます。

PoCで測定すべき値

Web FunctionsのCPU実働時間、メモリ使用量、全環境の累計アクティブ時間、実際の同時リクエスト数、応答時間p95、エラー率。通常Lambdaの平均実行時間も同じ負荷条件で計測してください。

関連資料：REST APIとWeb Functionsの採用比較 ／ AWS料金見積もり試算。各単価はAWS Lambda料金、API Gateway料金、CloudFront料金、WAF料金で再確認してください。
